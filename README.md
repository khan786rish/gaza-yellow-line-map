# The Map Is The Plan — Gaza's Yellow Line

Interactive map and documented evidence: Gaza's "yellow line", one year after the "ceasefire" — the encroachment, the erasure, and the evidence.

## Contents

- `index.html` + `data.js` — the interactive map (Leaflet + OpenStreetMap/CARTO tiles). Toggleable layers: both yellow lines, the seized band, the Israeli-held zone, corridors, outposts, strikes, crossings, the ISF staging base, displacement arrows, and five numbered evidence sites with sourced popups.
- `Gaza-Yellow-Line-Report.md` — the full written report behind the map.
